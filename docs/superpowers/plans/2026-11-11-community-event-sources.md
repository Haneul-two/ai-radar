# AI 행사 발견 출처 확장 계획

목표: 승인된 지피터스 발견 후 공식 확인, 모두의연구소, 서울 AI 허브를 추가해 배포한다. DACON 제외 변경을 포함하고 UI·마감 필터·수집 주기를 유지한다.

1. 공개 robots와 목록·상세를 조사한다. 검증: 허용된 공개 경로만 사용하고 실제 날짜·모집 근거가 존재한다.
2. 독립 모듈 gpters.py, modulabs.py, seoulaihub.py와 최소 공식 페이지 해석 모듈을 작성한다. 테스트 먼저 작성하고 기존 코드 실패 후 통과를 확인한다. 공통 Fetcher의 robots·호스트·크기·속도 제한을 유지한다. 지피터스는 뉴스레터 sitemap으로 글을 발견하고 명시적으로 허용된 공식 호스트에서 확인된 행사만 저장한다. 미지원 공식 호스트는 임의 조회하지 않고 건수로 보고한다.
3. 레지스트리·정확한 허용 호스트·관련 문서만 변경한다. 새 출처별 수집 한도와 실패 보존을 검증한다. 개인정보는 저장하지 않는다.
4. Python·Node 전체 검사, offline 검증, 새 출처 소량 실제 조회와 새 데이터 계약 검증을 수행한다. 다른 모델로 교차 리뷰하고 지적을 반영한다.
5. 기존 원격 자동 데이터 커밋을 보존하고 승인된 변경만 커밋·푸시·배포한다. 운영 수집과 Pages 갱신을 확인하고 공개 데이터의 새 출처·시각·실패 상태를 검증한다. 실제 확인한 결과만 docs/HISTORY.md와 지시 파일에 기록한다.

사용자 승인: 이 조합만 반영하고 배포. 기존 작업 폴더에서 진행하며 별도 worktree를 만들지 않는다. 불필요한 화면 변경과 이벤터스 수집은 포함하지 않는다.
