# AI Radar 디자인 비교 시안 4종 (2026-10-29)

운영 화면을 바꾸지 않는 **가산형 탐색**이다. 사용자가 "하늘 창고 디자인 선반 참고해 개선"을 요청했고 "시안부터 비교"를 골랐다. 운영 적용은 시안 선택 뒤 별도 작업이다.

## 보는 법
저장소 루트에서 `.venv/Scripts/python.exe -m http.server 8012 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8012/design-lab/shelf-20261029/index.html`.
파일을 더블클릭(file://)하면 안 된다 — ES module과 `../../data/*.json` fetch가 브라우저에서 막힌다.

## 시안 차이
| | 구조 | 색 | 글자 | 밀도·읽기 리듬 |
|---|---|---|---|---|
| 01 포커스 | 얇은 왼쪽 필터 + 6열 비교 행(좁은 폭은 라벨 붙은 2열) | forest green + 미색, 마감만 amber | 고딕, 중간 위계 | 촘촘, 행 단위 비교 |
| 02 에디토리얼 | 사이드바 없음, 번호 목록 + 오른쪽 마감 요약 열 | 웜 페이퍼 + 잉크 + 적갈색 | 바탕체(시스템) 큰 제목, 고딕 본문, 이탤릭 없음 | 느슨, 큰 제목·큰 마감 숫자 |
| 03 디스커버 | 상단 분류 탭 + 큰 검색 + 3열 카드(태블릿 2·모바일 1) | 회청색 + deep navy, 마감 임박 밴드만 peach | 고딕, 카드 제목 강조 | 카드 훑기, 하단 마감 밴드 |

## 데이터·로직 (새 판정 없음)
- 운영 `assets/`를 그대로 재사용: `dom.js h()`, `filters.mjs`(selectItems·facetCounts), `status.mjs getDeadline`, `visibility.mjs listedItems`, `data.mjs loadBoardData·datasetFreshness·itemFlags`, `format.mjs`, `safe-url.mjs`.
- `loadBoardData`에 `url => fetch('../../' + url)` 어댑터를 넘겨 실제 `data/opportunities.json` + `ingest-status.json`을 읽는다. 데이터는 읽기만 한다.
- 마감·종료 제외, 날짜(서울), D-day는 모두 운영 로직 결과. 값이 없으면 '확인 필요'. 건수·갱신 시각은 실제 값.
- 4개 모두 전체 항목을 그린다(미리보기 일부만 보여주지 않으므로 'N건 중 12건' 문구는 쓰지 않았다).
- 외부 네트워크 자산·폰트·이미지 없음. 문자열은 `h()`/text node만, innerHTML 없음.

## 공통 기능
검색(200ms debounce), 유형(전체/행사/공모전/해커톤), 참가 방식(전체/온라인/오프라인/혼합), 정렬(마감순/개최순), 로딩 스켈레톤, 빈 결과 + 조건 초기화, 불러오기 실패 + 다시 시도. 검색 입력과 선택 그룹은 한 번만 만들고 값·건수만 갱신해 포커스·캐럿을 유지한다. 지연·출처 실패는 목록 끝의 작은 문구로만 알린다.
- 04 플래너에만 기간 pill(전체/7일 내/30일 내/마감일 확인 필요)이 있고 실제로 목록을 좁힌다. 정렬이 개최순이어도 그룹은 마감 날짜순이며 그룹 안 순서만 바뀐다.
- 04 모바일은 날짜 그룹을 위에서 아래로 쌓는 카드로 보여준다(한 번에 한 그룹만 보이는 페이지 넘김은 아님).

## 운영 기능 보존 방침 (시안에서 일부러 뺀 것)
저장(북마크), 달력 보기, 상세 패널, 상태 필터, URL 상태, `?debug`는 시안에 구현하지 않았다. 작동하지 않는 버튼을 만들지 않기 위해서다. 시안이 채택되면 운영 `index.html`의 기존 기능(저장·달력·상세·마감 제외 판정)을 **보존한 채** 시각 구조만 옮긴다.
- 안내 링크는 '공식 신청'이라 부르지 않는다(집계 사이트일 수 있음). 제목 링크는 줄바꿈 허용, 메뉴·조작 링크는 한 줄.

## 접근성·모션
조작 목표 44px 이상, `:focus-visible` 3px 외곽선, hover/focus 전환 120ms, `prefers-reduced-motion`에서 전환·스켈레톤 애니메이션 제거.
